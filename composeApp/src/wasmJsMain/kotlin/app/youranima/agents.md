# app.youranima (wasmJsMain) — web entry point

- `Main.kt`: `ComposeViewport("composeTarget")` → `App()`. First awaits `loadPreloadedResources()`, then mounts `App()` on an `InMemoryResourceReader` (provided as `LocalResourceReader`), and hides the HTML/CSS loader from `resources/index.html` (`#loader`, styles in `styles.css`) after the first frame, which is then fully styled: Geist, avatars, icons and all strings (#70). Binds the app's nav controller to the browser history (`App(onNavHostReady = { it.bindToBrowserNavigation() })`, #66): the paywall gets `#paywall`, browser back closes it. The paywall's X goes through the same history (`App(onCloseScreen = { window.history.back() })`), so X doesn't add an entry that browser back would reopen.
- `InMemoryResourceReader.kt` (#70, web startup): the production `index.html` starts downloading the first screen's composeResources right after it is parsed (an inline script fills `window.webPreloads`, path → promise of the bytes; wasm and `composeApp.js` get `<link rel="preload">`). Both are generated by the `wasmJsBrowserDistribution` post-step in `composeApp/build.gradle.kts`, which picks files by name: all fonts, `drawable/home_*`, `drawable/ic_*`, `values/strings(_home).commonMain.cvr`. `loadPreloadedResources()` collects them while the skiko wasm is still downloading; `InMemoryResourceReader` serves them from memory without suspending (Compose's web reader goes through Cache Storage for every single string, so texts would trickle in over ~2 s) and delegates everything else to Compose's reader. The dev server has no preloads: the map is empty and Compose loads everything itself.
- `WebGlContextRecovery.kt` (#65): Chrome on Android drops the WebGL context of background tabs and skiko never restores it (blank, dead canvas). `reloadOnWebGlContextLoss` polls for the Compose canvas under `#composeTarget` (also inside shadow roots, up to 10 s), listens for `webglcontextlost`, shows the loader again and reloads the page once: immediately if the tab is visible, else on the next `visibilitychange` to visible.
- `ui/navigation/AppReloader.wasmJs.kt`: the web `actual` of `appReloader` (pull-to-reload, see `commonMain/.../ui/navigation/agents.md`).

A killed renderer (sad-tab, memory pressure) can't be handled from code; the page just loads fresh next time.
